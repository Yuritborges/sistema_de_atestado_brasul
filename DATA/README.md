# Pasta de dados (não vai para o Git)

Na rede Brasul, os dados ficam em:

`Z:\0 OBRAS\Sistema_de_atestado_brasul\DATA\`

| Subpasta | Conteúdo |
|----------|----------|
| `input\` | `Cofre_atestados_brasul.xlsx` (planilha mestre) |
| `output\` | `Cofre_Brasul.xlsx` (cópia para consulta) |
| `backup\` | Backups automáticos |
| `logs\` | Histórico e cadastros |

Copie `deploy\rede.path.example` para `deploy\rede.path` com o caminho da sua `DATA`.
